# 练习目录

这里放**学习过程中的练习题和解答**,与教材原始的 `LA_*.pdf` / `LA_*.ipynb`(参考答案)分开,避免弄乱 fork。

## 命名约定

- `LA_XX_YY_练习.ipynb` —— 某一小节的练习(题目 + 我的解答)
- `LA_XX_YY_笔记.md` —— 自己的文字笔记(可选)
- 想动手改教材代码时,**复制**对应的 `LA_XX_YY_ZZ.ipynb` 到这里再改,别动原件。
