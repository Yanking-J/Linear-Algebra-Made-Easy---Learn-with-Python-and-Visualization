1.2坐标系

向量是一列数。坐标系，就是把这列数变成看得见的箭头的那座桥。

本节进度 ① 实数数轴 ② 平面直角坐标系 ③ meshgrid 网格 ④ 单位向量与分解 ⑤ 三维坐标系 ⑥ 向量长度
①

实数数轴

画一条直线，向左右无限延伸——这就是实数数轴（real line）。向左趋向负无穷 −∞，向右趋向正无穷 +∞。

别看它简单，它必须同时具备三个要素，缺一个就没法用：

要素是什么拿掉它会怎样
原点0 在哪不知道从哪儿开始数
正方向箭头朝哪不知道哪边是正、哪边是负
单位长度1 有多长知道方向，但不知道「走了多远」

打个比方：这就像看一把尺子。原点是刻度 0 的位置，正方向是刻度增大的方向，单位长度是一厘米有多宽。三者齐了，尺子才能量东西。

数轴还有个正式名字：一维欧几里得空间，记作 ℝ，也就是全体实数的集合。

为什么要强调三要素

因为二维、三维坐标系不过是把这套三要素在每根轴上各配一份。等会儿讲平面坐标系时你会看到，它就是两条数轴垂直一交叉，没有任何新东西。先把一维吃透，后面全是复用。

②

平面直角坐标系

两条数轴在原点垂直一交叉，就是平面直角坐标系，也叫二维欧几里得空间 ℝ2。每根轴各自带一套「原点 / 正方向 / 单位长度」，没有新东西。

笛卡尔与苍蝇

17 世纪笛卡尔（René Descartes）躺床上盯着天花板上的苍蝇，想到可以用两条垂直数轴锁定苍蝇的位置。这一念之间，几何问题变成了解方程——解析几何就此诞生。所以它也叫「笛卡尔坐标系」。

高中的部分到此为止。下面三条是本书的约定，值得停一下。

约定一：向量的起点，默认在原点

列向量画成箭头：起点 (0, 0)，终点 (x1, x2)。

x = x1 x2

这条约定的意义在于——坐标值就唯一确定了一个向量，不用再交代「它在哪」。零向量 0 就趴在原点。

但注意「默认」二字：向量是可以平移的。下一节讲向量加法时，就要把一个箭头的尾巴挪到另一个箭头的头上，摆成「首尾相接」。那时候起点就不在原点了。

约定二：两种画法 —— 箭头 vs 散点

画法什么时候用
箭头（arrow / quiver）向量少，关心起点终点的具体位置
散点（scatter）向量多，只关心分布和趋势

散点图里，每个点就是一个向量的终点（起点默认在原点，省略不画）。

这在机器学习里对应什么

你以后见到的每一张「数据散点图」，本质上都是一堆向量的终点。一个数据样本 = 一个向量 = 图上一个点。这个翻译关系记住，第 12 章讲 PCA 时会直接用上。

约定三：逆时针为正

从 x1 轴正方向逆时针转 90°，到 x2 轴正方向——规定这个方向为正。

这条最重要

听起来像废话，但它是个约定，不是定理。而且后面一大串东西的正负号全挂在它身上：行列式的正负、叉积的方向、旋转角的符号。约定一反，这些结论全部变号。三维里它会升级成右手定则。

教材把 x1 轴画成红色、x2 轴画成绿色，不是随便挑的。后面要用 RGB 颜色来讲二维向量——红绿平面上的点，就是红光绿光按不同比例混出的颜色。

§

符号速查表

数学公式的标准写法叫 LaTeX（读作「拉泰赫」），是论文和教科书的通用排版语言。它既不是 Python 代码，也不是字体设置——而是「这段是公式」的标记。下面是本节用到的对照，看到原始码时可以回来查。

LaTeX 写法渲染结果怎么读意思
$ ... $ （界定符） —— 「这中间是公式」
\boldsymbol{x} x 向量 x 粗斜体 = 向量
x_1 x1 x 下标 1 第 1 个分量
x^2 x2 x 的平方 上标 / 幂次
\begin{bmatrix} ... \end{bmatrix} x1 x2 方括号矩阵 画一个矩阵 / 列向量
\\ （换行） —— 矩阵里换到下一行
\mathbb{R}^2 ℝ2 R 二 二维欧几里得空间
\|\boldsymbol{x}\| ‖x‖ x 的范数 向量的长度（小点 ⑥ 讲）
纯文本写法

在不能渲染公式的地方（比如聊天窗口），同样的意思可以直接写成 x = [x₁, x₂]ᵀ。右上角那个 ᵀ 是转置——把横着写的一行数立起来变成一列，这样列向量就能写在一行里了。
