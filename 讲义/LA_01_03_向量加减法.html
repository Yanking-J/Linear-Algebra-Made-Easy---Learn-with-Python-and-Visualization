1.3向量加减法

加法就是「接着再走一段」。一句话说完了，剩下的全是几何直觉和它带来的性质。

本节进度 ① 向量加法 ② 平行四边形法则 ③ 平行六面体 ④ 三角形法则与交换律 ⑤ 结合律 ⑥ 向量减法
①

向量加法 —— 对应分量相加

定义只有一句话：两个维数相同的向量相加，就是把它们对应位置的分量分别相加，结果还是同维数的向量。

a + b = a1 a2 ⋮ an + b1 b2 ⋮ bn = a1 + b1 a2 + b2 ⋮ an + bn

注意两件事：

  • 维数必须相同。二维向量加不了三维向量——没有「对应位置」可言。
  • 各分量互不干扰。第 1 个分量只跟第 1 个分量打交道，第 2 个只跟第 2 个。加法是「并排各算各的」，不是把它们搅在一起。

直觉：走两段路

把向量读成「走一段路」。a = [4, 1]T 是「向右 4、向上 1」，b = [1, 2]T 是「向右 1、向上 2」。先走 a 再走 b，一共向右 5、向上 3。

4 1 + 1 2 = 5 3

「向右走的账」和「向上走的账」是分开记的两本账——这就是分量为什么互不干扰。

教材的例子：RGB 混光

三个分量各管各的通道，互不串门——「加法各分量独立」这件抽象的事，在这里就是「三盏灯各调各的亮度」。全关是黑 [0, 0, 0]T，也就是零向量。

NumPy 怎么写

一个加号，没了。

import numpy as np

a_vec = np.array([4, 1])
b_vec = np.array([1, 2])

a_plus_b = a_vec + b_vec
a       = [4 1]
b       = [1 2]
a + b   = [5 3]    <- [4+1, 1+2]

NumPy 看见两个数组相加，会自动逐个分量配对，不需要你写循环。这个特性叫向量化（vectorization），上一节 xx1**2 + xx2**2 用的就是它。

坑：list 的 + 不是加法

Python 原生列表的 + 是拼接，不是数学加法：

[4, 1] + [1, 2]   ->  [4, 1, 1, 2]     # 接成 4 个数
np.array([4,1]) + np.array([1,2])  ->  [5 3]   # 这才是加法

不报错，但结果全错——所以做数学之前，一定先 np.array() 转成数组。

维数不同会报错 
np.array([1,2]) + np.array([1,2,3])
ValueError: operands could not be broadcast together
            with shapes (2,) (3,)

看到 shapes (2,) (3,) 就知道是两个数组长度对不上。broadcast（广播）这个词后面会正式讲，现在只要认得这个报错长什么样。

②

几何视角:平行四边形法则

平行四边形法则(parallelogram law):把 a、b 的起点对齐在原点，以它们为邻边构造一个平行四边形；从原点出发的那条对角线，就是 a + b。

拿上一小点的例子 a = [4, 1]T、b = [1, 2]T 来画：

两条虚线分别平行于 a、平行于 b，把图形补成一个四边形。四条边两两平行——这正是「平行四边形」名字的来源。对角线从原点指向的那个角，坐标恰好是 [5, 3]T，和逐分量相加的结果完全一致。也就是说：代数上的「分量相加」和几何上的「构造对角线」，是同一件事的两种说法。

特例:a、b 共线时,平行四边形「塌」了

如果 a、b 方向相同或相反（共线，collinear），就找不到第二个方向来撑开平行四边形——a + b 仍然落在同一条直线上。零向量 0 也算共线的极端情况（长度为 0，没有方向）。教材图 4 画了这两种子情况，可以翻 PDF 第 4 页对照看。

零向量:加法的「不动点」

零向量 0 = [0, 0, …, 0]T 有个特殊身份——加法单位元（additive identity）：

a + 0 = a

任何向量加上零向量，都原地不动。RGB 类比：零向量对应黑色（没有任何光），黑色和任何颜色混合，那个颜色都不会变。

zero = np.array([0, 0])
a_vec + zero
a + 0 = [4 1]   <- 加零向量,自己不变

代码:plt.quiver() 画向量

图 2 是用 练习/LA_01_03_代码.py 的小点2_平行四边形法则() 画的，核心是 plt.quiver(起点x, 起点y, 分量x, 分量y, ...)：

plt.quiver(0, 0, a_vec[0], a_vec[1],
           angles='xy', scale_units='xy', scale=1,
           color='r', label="a")

angles='xy' + scale_units='xy' + scale=1 这三兄弟必须一起出现——意思是「箭头按坐标轴的实际单位画，不做任何缩放」。少了它们，quiver 默认会按图窗大小自动缩放箭头，长度就不准了。

③

平行六面体 —— 三个向量相加

平行四边形法则管的是两个向量。三个向量 a、b、c 相加，几何上对应一个平行六面体（parallelepiped）——六个面都是平行四边形的立体图形。

做法其实就是把平行四边形法则用两次：先用 a、b 构造一个平行四边形，对角线是 a+b；再把这条对角线当成新的一条边，和 c 构造第二个平行四边形，第二条对角线就是 a+b+c。整个六面体的主对角线，就是三个向量之和。

最干净的例子还是 RGB：红 e1、绿 e2、蓝 e3 三条邻边，撑出一个单位正方体，主对角线正是三色光叠加的结果——白色 [1,1,1]T。

浅灰色那个面，是 e1、e2 撑出的平行四边形（第一次用平行四边形法则）；再把 e3 加上去，主对角线捅穿整个立方体（第二次用平行四边形法则）。三个向量的加法，本质上就是两次两个向量的加法。

特例:三个向量共面时,「六面体」塌成平面

如果 a、b、c 恰好在同一个平面上（共面，coplanar），撑不起第三个维度，六面体退化成一个平行四边形。更特别的情况——如果三个向量首尾相接正好围成一个封闭三角形，那么它们的和是零向量 0：从起点出发按顺序走一圈，正好走回起点。这正是下一小点「三角形法则」的引子。

④

几何视角:三角形法则与交换律

三角形法则(triangle law):把 b 的起点挪到 a 的终点(首尾相接)，从 a 的起点指向 b 的终点的那条有向线段，就是 a + b。

这跟小点①「走两段路」的直觉完全对应：先走 a，再接着走 b，最终位置就是 a+b。比起平行四边形法则，它不用补虚线——三条边直接就是一个三角形。事实上，平行四边形的对角线本来就能把平行四边形切成两个全等三角形，三角形法则用的正是其中一半。

实线路径是「先走 a(红)、再走 b(绿)」；虚线路径是「先走 b、再走 a」。两条路径终点重合——这就是向量加法交换律:

a + b = b + a

直觉上不难理解：走两段路，先往东走还是先往北走，只要两段都走了，最终到达的位置是一样的。

还是那句话:共线就围不成三角形

和平行四边形法则一样，如果 a、b 共线，三条边会重叠在同一条直线上，围不出真正的三角形——但 a+b 这个「终点」依然存在，只是三点共线退化成了一条线段。

代码:quiver 的起点从原点挪开

对照 练习/LA_01_03_代码.py 里的 小点4_三角形法则()，和小点②的代码相比，唯一的区别就是画 b 那一行：

# 平行四边形法则(小点②): b 也从原点出发
plt.quiver(0, 0, b_vec[0], b_vec[1], ...)

# 三角形法则(小点④): b 的起点挪到 a 的终点
plt.quiver(a_vec[0], a_vec[1], b_vec[0], b_vec[1], ...)

plt.quiver(x, y, u, v, ...) 的前两个参数 (x, y) 永远是箭头起点，不一定非得是原点。把起点从 (0, 0) 换成 (a_vec[0], a_vec[1])，画出来的箭头就是「从 a 的终点出发」——这一个改动，就把平行四边形法则变成了三角形法则。

⑤

多向量首尾相连与结合律

三角形法则不止能加两个向量。把它重复使用:a 的终点接 b 的起点，b 的终点接 c 的起点……依次首尾相连，从最初起点指向最终终点的箭头，就是全部向量之和。

这跟小点③的平行六面体是同一件事的两种画法:平行六面体是「两次平行四边形法则」，这里是「三次三角形法则」——殊途同归，终点都是 a+b+c。RGB 版本可以翻 PDF 第 12 页图 13:红、绿、蓝依次首尾相连，终点正是白色。

结合律:先加哪两个,结果都一样

三个以上向量相加，先算哪两个都不影响最终结果:

(a+b) +c = a+ (b+c)

这就是向量加法结合律(associative law)。PDF 第 12–14 页图 14、图 15 画了好几条不同分组路径，都指向同一个白色向量，可以对照着翻一翻。

为什么结合律"理所当然"成立

小点①讲过:向量加法就是分量各自相加。而普通实数的加法早就满足结合律 —— (3+1)+5 = 3+(1+5)，小学就学过。向量不过是把这件事在每个分量上各做一遍：分量满足的结合律，向量自然继承。这也是这门课一个常见的套路:向量的性质，往往可以拆回"每个分量都是普通实数"去理解。

交换律 + 结合律:a+b+c 不用纠结括号

把小点④的交换律和这里的结合律放在一起:不管加的顺序、不管先加哪两个，结果永远一样。这就是为什么可以放心写 a+b+c、a+b+c+d……而不用给每次加法都标括号——反正标在哪儿结果都相同。

a = np.array([3, 1])
b = np.array([1, 2])
c = np.array([-1, 2])

(a + b) + c   # [3 5]
a + (b + c)   # [3 5]  <- 一样
(a + c) + b   # [3 5]  <- 还是一样
(3 + 1) + 5 = 9    3 + (1 + 5) = 9   <- 分量层面就是这么回事
⑥

向量减法

减法和加法是同一套路数:对应分量相减。

a − b = a1 − b1 a2 − b2 ⋮ an − bn

RGB 类比:减去一个颜色向量，相当于过滤掉这个颜色。黄减红剩绿——黄色本来就是红光加绿光，拿走红光，自然只剩绿光:

黄 [1 1 0]  - 红 [1 0 0]  =  [0 1 0]  绿

减法 = 加上"相反向量"

减法可以完全用加法改写:

a − b = a + (−b)

−b 叫 b 的相反向量(opposite vector)：长度和 b 一样，方向正好相反。它是向量加法的逆元——正好和小点②的零向量 0 对应上:0 是加法的单位元(a+0=a，加了等于没加)，−b 是加法的逆元(b+(−b)=0，加了正好抵消)。有了「加法 + 单位元 + 逆元」这三件套，减法就不用单独定义一套新规则，直接套用加法的所有性质。

关键几何直觉:a−b 是"从 b 指向 a"的箭头

这是本节最值钱的一条直觉，以后全书都会用到。设 c = a − b，两边加上 b:

b + c = a

按三角形法则读这个等式:从 b 的终点出发，走一段 c，恰好到达 a 的终点。也就是说——如果 a、b 都是从原点出发的箭头(各自代表一个"点")，那么 a−b 就是从 b 指向 a 的那支箭头。

这条直觉在后面几乎每一章都会用到:两点之差 = 从一点指向另一点的箭头。比如以后讲"数据点之间的距离"，第一步永远是先做减法，把两个点的坐标差变成一个方向明确的向量。

a = np.array([4, 1])
b = np.array([1, 3])

a - b          # [ 3 -2]
a + (-b)       # [ 3 -2]   和上面相等
b - a          # [-3  2]   正好是 a-b 的相反数
